# Сервис для сбора, хранения и мониторинга уровней водохранилищ

Сервис предназначен для автоматического сбора, хранения и визуализации данных об уровнях водохранилищ с сайта https://rushydro.ru/informer/ .

## 🛠️ Стек технологий

**Backend:** JDK Corretto 17.0.13, Spring Boot, Hibernate, P6Spy 
**Database:** PostgreSQL 16.6  
**Web:** Tomcat, Thymeleaf, JSTL  
**Парсинг данных:** Selenium Grid 4.31.0, Chrome Node  
**Инфраструктура:** Docker Compose 3.8, Docker Networking

## ✨ Основные возможности

- **Автоматический сбор данных:** Периодический парсинг данных с сайта [rushydro.ru/informer/](https://rushydro.ru/informer/) с использованием Selenium Grid
- **Ручной запрос данных:** Возможность получить данные за конкретную дату для выбранной Реки и ГЭС
- **Визуализация:** Построение графика уровня воды за выбранный период для выбранной Реки и ГЭС
- **REST API:** Четкое разделение фронтенда и бэкенда для взаимодействия по API
- **Контейнеризация:** Полная изоляция сервисов через Docker Compose

## 🏗️ Архитектура проекта

Сервис развертывается в виде шести взаимосвязанных Docker-контейнеров:

| Контейнер       | Назначение                                          | Порт  | Зависимости            |
|-----------------|-----------------------------------------------------|-------|------------------------|
| **autocrawling**| Сервис автоматического сбора данных                 | 8082  | postgres, selenium-hub |
| **backend**     | Основной бэкенд-сервис (REST API, бизнес-логика)    | 8081  | postgres               |
| **frontend**    | Веб-интерфейс для пользователя                      | 8080  | backend                |
| **selenium-hub**| Центральный хаб для управления Selenium Grid        | 4444  | -                      |
| **chrome**      | Node с браузером Chrome для автоматического парсинга| -     | selenium-hub           |
| **postgres**    | База данных PostgreSQL для хранения всех данных     | 5432  | -                      |




## 🚀 Быстрый старт

1. Убедитесь, что у вас установлены **Docker** и **Docker Compose**
2. Клонируйте репозиторий или поместите файлы проекта в рабочую директорию
3. Запустите сборку и запуск всех контейнеров командой:
```bash
docker-compose up --build -d 
```
4. После успешного запуска откройте в браузере: http://localhost:8080


## 📊 Мониторинг
Все контейнеры имеют healthcheck и автоматически перезапускаются при сбоях. Сеть selenium-network обеспечивает изолированное взаимодействие между сервисами.

## 🗄️ Данные
В папке dumps находится дамп базы данных, предзаполненный данными по всем ГЭС реки Волга. Его можно использовать для инициализации или восстановления БД.
